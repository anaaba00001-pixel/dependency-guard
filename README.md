# Dependency Guard

منصة ويب عربية مستقلة لفحص ثغرات الاعتماديات باستخدام OSV-Scanner. تشمل المرحلة الأولى واجهة RTL متجاوبة، رفع ملفات lockfiles، لوحة مخاطر، إصلاحات مقترحة، سجلًا مؤقتًا، وتصدير JSON/CSV.

## التشغيل المحلي

المتطلبات: Node.js 22+ وملف `osv-scanner` التنفيذي في `PATH`.

```powershell
npm install
Copy-Item .env.example .env
npm run dev
```

الواجهة: `http://localhost:5173`، والـ API: `http://localhost:8080`.

عند عدم توفر OSV-Scanner يمكن تجربة الواجهة محليًا فقط بتعيين `SCANNER_MODE=mock`. يُعطّل هذا الوضع تلقائيًا في الإنتاج.

## ضوابط الأمان الحالية

- قائمة سماح مغلقة لأسماء ملفات الاعتماديات وحد افتراضي 5MB.
- Rate limiting وحد أقصى لعمليات الفحص المتزامنة.
- مجلد مؤقت عشوائي وصلاحيات `0600` وحذف مضمون بعد الفحص.
- تشغيل OSV-Scanner مباشرة دون Shell أو تنفيذ شيفرة المشروع.
- مهلة للفحص وحد لحجم الإخراج، وتشغيل الحاوية كمستخدم غير root.
- CORS محصور في `WEB_ORIGIN` وترويسات Helmet الأمنية.

قبل استقبال ملفات عامة بكثافة، يجب نقل عامل الفحص إلى حاوية أو Queue مستقلة بحدود CPU والذاكرة والشبكة.

## الاختبار والبناء


## النشر

- **Vercel:** انشر جذر المستودع واضبط `VITE_API_URL` بعنوان خدمة Render.
- **Render:** استخدم Blueprint من `render.yaml` واضبط `WEB_ORIGIN` على نطاق Vercel النهائي.
- صورة Render تبني OSV-Scanner `v2.7.0` من المصدر.
